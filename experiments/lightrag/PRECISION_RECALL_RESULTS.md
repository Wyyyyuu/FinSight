# LightRAG + Neo4j 检索评测（2026-09-16）

**结论：本轮没有观察到图辅助方案优于同等子问题分解的混合检索基线。**
当前 guarded 图辅助方案的整题 Precision@8 为 **29.17%**，Recall@8 为 **55.95%**；
匹配基线分别为 **33.33% / 64.29%**。Neo4j 与 NetworkX 重跑结果一致，差异来自候选选择及融合策略。

## 范围与口径

- 真实执行本机 Neo4j 检索；复用 BGE-M3 向量和关键词缓存，0 次新外部模型或嵌入调用。
- 使用旧英文 FinQA 开发簇：6 份报告、501 个原始证据片段、78 个建图块，563 个实体、686 条关系。
- 主表为 3 个构造复合问题：跨公司、跨年度、三报告汇总。辅助表为其中 7 个不同但有关联的子问题。
- 主表每道完整问题共享最多 8 条原文 / 3000 token；辅助表每个子问题单独享有此预算，两表不能混合比较。
- 所有方案均不重排，以隔离检索策略影响；这不是主应用带重排的全量评测。
- 精确率为 `命中的标注证据 ID 数 / 8`，召回率为 `命中的标注证据 ID 数 / 标注证据 ID 总数`，再按题宏平均。
- 主结果采用既有标注审计：跨年度题补上漏标的分子证据。原始标签评分也完整保留在 JSON；不因历史数值单位歧义剔除任何检索题。
- 标注不是穷尽相关性判断：重复表格、同义片段或有用旁证不在指定 gold IDs 中也不计命中。这里不能把 `1 − Precision` 当成实际无关内容比例。
- 三道整题的 gold 数为 4、3、7。因此固定 K8 的宏平均 Precision 理论上限为 **58.33%**；不是所有题都存在 8 条已标注证据。

## 整题结果：共享 K8

| 方案 | Precision@8 | Recall@8 | nDCG@8 | 全部标注证据齐备 |
|---|---:|---:|---:|---:|
| BGE-M3 稠密向量，整题检索 | 33.33% | 65.08% | 59.11% | 33.33% |
| BGE-M3 + BM25/RRF，整题检索 | 25.00% | 45.63% | 53.54% | 0.00% |
| BGE-M3 + BM25/RRF，分解子问题并均衡取证 | **33.33%** | **64.29%** | **58.83%** | **33.33%** |
| LightRAG naive，整题检索 | 8.33% | 15.87% | 14.73% | 0.00% |
| LightRAG mix，整题图检索 | 4.17% | 4.76% | 9.16% | 0.00% |
| 子问题混合检索 + 图候选直接 RRF 融合 | 12.50% | 20.63% | 24.81% | 0.00% |
| 当前 guarded：保护各子问题前两条基础候选，再加入图候选 | **29.17%** | **55.95%** | **54.73%** | **33.33%** |

整题各臂实际都返回 8 条，因此按实际返回条数计算的精确率与表中 Precision@8 相同。
不同 query 分解方式是不同实验因素：不能把 guarded 相比整题混合检索的差异全部归功于图谱。
最直接的图辅助对照是“分解子问题并均衡取证”与 guarded，两者使用相同问题分解和最终预算。

| 案例 | 基础均衡取证：命中 / gold | 当前图辅助：命中 / gold | 基础 Recall@8 | 图辅助 Recall@8 |
|---|---:|---:|---:|---:|

| 跨年度 | 3 / 3 | 3 / 3 | 100.00% | 100.00% |
| 三报告汇总 | 3 / 7 | 3 / 7 | 42.86% | 42.86% |

跨公司案例在图候选融合后失去原先命中的 `F12106d63b7eefe5317`。
“保护前两条候选”能够限制干扰，但不能保证整题最终 8 条上下文保留所有有用基础证据。
图谱候选、建图块到原始行的映射和最终预算分配仍有优化空间。

## 子问题辅助结果：每个子问题单独 K8

| 方案 | Precision@8 | Recall@8 | 全部标注证据齐备 |
|---|---:|---:|---:|
| BGE-M3 稠密向量 | 23.21% | 92.86% | 85.71% |
| BGE-M3 + BM25/RRF | 25.00% | 100.00% | 100.00% |
| LightRAG mix | 16.07% | 64.29% | 57.14% |
| 图候选直接融合 | 19.64% | 76.19% | 71.43% |
| 当前 guarded 图辅助 | 21.43% | 90.48% | 85.71% |

LightRAG mix 在此表平均只返回 7.43 条，按实际返回条数计算的宏平均标注精确率为 19.64%；
它与固定分母为 8 的 16.07% 是不同口径。其他臂均返回 8 条。
这些子问题结果表明：基础混合检索能覆盖已标注原文，但整题共享 8 条证据时仍会损失覆盖。
这不能解释成“多文档 RAG 的召回率已经达到 100%”。

## 验证与复现

- Neo4j 和 NetworkX 各实际执行 13 次检索：7 次子问题 mix、3 次整题 mix、3 次整题 naive。
- 两个后端全部 **56 条评分记录一致**（21 条整题记录 + 35 条子问题记录），无失败被排除。
- 原始索引文件哈希保持不变。评分预算、语料哈希、标签哈希和代码指纹在检索前写入计划。
- 新增评分测试及相关迁移/多文档检查共 **19 项通过**。
- 本轮不生成答案，不测事实正确率，不用缓存耗时声称线上性能提升。
